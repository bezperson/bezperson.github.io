Покладіть сюди зображення ваших сертифікатів та дипломів.

Рекомендації:
- Формат: JPG або PNG
- Назви: cert-1.jpg, cert-2.jpg, cert-3.jpg, cert-4.jpg
  (саме на ці назви посилається index.html — за потреби змініть їх там)
- Орієнтація: вертикальна (книжкова) виглядає найкраще
- Розмір: до ~1500 px по довшій стороні, щоб сторінка швидко завантажувалась

Після додавання файлів замініть у index.html:
  src="assets/cert-placeholder.svg"  →  src="assets/certs/cert-1.jpg"
  href="assets/certs/cert-1.jpg"      (залишається таким самим)
